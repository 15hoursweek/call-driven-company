# user_todo/ — 人間にしかできない作業

- 1ファイル = 1TODO。ファイル名は `{YYYYMMDD}_{状態}_{要点}.md`
- 日付は作成日で固定（状態が変わっても変えない）
- 状態は `PENDING` を基本とする（定義は `LOOP_DESIGN.md` ②）。変更はファイル名のリネームで行う
- 判断が下りた／作業が終わったらファイルを削除する（履歴は git に残る）。このディレクトリには常に未消化だけがある
- 打ち合わせの冒頭でチャットがこのディレクトリを一覧し、ファイルがあれば提示する。ファイル名だけで要点が分かるようにする
- 関連するAI側の続き作業があれば、本文末尾に `→ 関連: ai_todo/ の該当ファイル名` を書く

このREADMEはディレクトリを空にしないために置いている。運用の正本は `LOOP_DESIGN.md`。
