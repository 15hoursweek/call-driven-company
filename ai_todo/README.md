# ai_todo/ — CodeCLIが実行するTODO

- 1ファイル = 1TODO。ファイル名は `{YYYYMMDD}_{状態}_{要点}.md`
- 日付は作成日で固定（状態が変わっても変えない）
- 状態は `未着手` / `要再試行` / `人間待ち`。変更はファイル名のリネームで行う（定義は `LOOP_DESIGN.md` ③）
- 完了したらファイルを削除する（履歴は git に残る）。このディレクトリには常に未消化だけがある
- 本文には背景・作業内容・完了条件・関連ファイルを書く。要約はファイル名で済むようにする

このREADMEはディレクトリを空にしないために置いている。運用の正本は `LOOP_DESIGN.md`。
